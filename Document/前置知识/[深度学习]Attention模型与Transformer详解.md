# Attention模型与Transformer详解

# 前言

在上一篇文章中，我们提到了Conformer的核心组件之一就是Self-Attention。如果你对注意力机制和Transformer还不太熟悉，这篇文章就是为你准备的。我们会从最直觉的动机出发，逐步推导到完整的Transformer架构——尽量不使用晦涩的术语，而是用你能感知到的逻辑来串联每一个设计决策。

# 第一部分：为什么需要Attention

## 一个直觉问题

假设你现在要翻译一句话：

> "The cat, which was sitting on the mat, **is** hungry."

当你要翻译动词"is"时，你需要知道它的主语是"cat"，而不是离它更近的"mat"。这是一个**长距离依赖**问题——"cat"和"is"之间隔着好几个词，但它们的语法关系是最紧密的。

在RNN/LSTM时代，模型试图用一个固定长度的**隐藏状态向量**来"记忆"所有过去的信息。这本质上是一个压缩操作：把整句话的上下文压缩成一个固定大小的向量。问题是：

- 压缩一定会丢失信息
- 距离越远，压缩损失越大
- 梯度在反向传播时逐时间步衰减（梯度消失）

## Attention的核心直觉

与其把所有信息压缩到一个向量里，不如**让模型在需要时，自己去"查找"相关的信息**。

这个直觉非常像一个你每天都在用的功能——微信的聊天记录搜索。当你搜"周五吃饭"时：

- 你在搜索框打的字，就是 **Query**（查询）：你想找什么？
- 每条消息被索引的关键词，就是 **Key**（键）：这条消息可以被什么样的查询找到？
- 匹配到之后返回给你看的完整消息，就是 **Value**（值）：你要拿走的实际信息是什么？

Attention做的事情正是如此：

1. 你有一个 **Query**：位置 i 说"我想知道谁跟我有关"
2. 你有一组 **Key**：每个位置 j 说"我身上挂着这些标签，你可以这样找到我"
3. 你有一组 **Value**：每个位置 j 说"如果找到了我，这是我贡献的实质内容"
4. 你通过比较 Query 和每个 Key 的相似度，得到一组权重
5. 用这些权重对 Value 做加权求和，得到输出

用大白话说：**Attention 允许每个输出位置"关注"所有输入位置，并根据相关性决定从每个位置获取多少信息。**

# 第二部分：深入理解 Q、K、V

> 这是整个 Attention 中最核心、也最容易困惑的部分。如果你对 Q、K、V 为什么存在以及它们是怎么来的有疑问，这一节就是为你写的。

## 2.1 前置认识：什么叫"信息的向量化"

神经网络只能处理固定长度的实数数组。向量化就是把世界里的东西（词、图像块、音频帧）映射成一个数字数组。

比如词"猫" → `[0.23, -0.71, 1.05, ..., 0.14]`，512维。这个数组就叫**嵌入向量（Embedding）**。语义相近的东西在空间中离得近："猫"和"狗"的距离比"猫"和"桌子"更近。音频也一样——每一帧的 Mel 频谱本身就是一个向量。

所以当我们在讨论 Q、K、V 时，它们始终在**同一个 $d$ 维空间**中运作，只是被不同的投影矩阵变换到了不同的"观察角度"。

## 2.2 Q、K、V 不是凭空生成的——它们就是同一个输入照了三面不同的镜子

假设输入的第 i 个位置有一个向量 $x_i$（比如一个词的 embedding），维度是 $d$：

$$q_i = x_i \cdot W_Q$$

$$k_i = x_i \cdot W_K$$

$$v_i = x_i \cdot W_V$$

其中 $W_Q$、$W_K$、$W_V$ 是三个**可训练的矩阵**，维度都是 $d \times d_k$。

**关键认知：同一个输入 $x$，经过三个不同的线性变换，变成了三个不同的向量 q、k、v。** 三个矩阵不是把向量"送到另一个空间"，而是在同一个 $d$ 维空间内做了三种不同的**旋转 + 拉伸**。

## 2.3 几何直觉：三个"透镜"

词向量 $x$ 已经在语义空间里有一个位置了。$W_Q$、$W_K$、$W_V$ 做的事，是把同一个 $x$ 从三个不同的角度重新观察：

| 透镜 | 它的作用 | 几何效果 |
|------|---------|---------|
| $W_Q$ | 把 $x$ 旋转成"我在找什么"的方向 | 提取"查询意图" |
| $W_K$ | 把 $x$ 旋转成"我是什么、可以被找到吗"的方向 | 提取"被查标签" |
| $W_V$ | 把 $x$ 旋转成"我被找到后贡献什么信息"的方向 | 提取"实质内容" |

同一个"猫"，在三面不同的透镜下呈现出三个侧面：
- q("猫")：强调"猫"作为查询者的身份——比如它在问"我被谁追？"
- k("猫")：强调"猫"作为被查者的标签——比如"我是一个名词 / 动物 / 主语候选"
- v("猫")：强调"猫"的完整语义内容——"毛茸茸、会喵叫的实体"

## 2.4 为什么要分成三个投影而不直接用原始向量？

因为在原始的语义空间里，"猫"和"狗"离得近（都是动物），"猫"和"追"离得远。但这个距离反映的是**语义相似度**，不一定是**"谁和谁在句子里有语法 / 上下文关系"**。

用 $W_Q$ 和 $W_K$ 投影后，模型可以自己学会：

- q("追") 和 k("猫") 的点积很大 → "追"想知道主语是谁，"猫"说我是名词
- q("追") 和 k("鱼") 的点积也很大 → "追"想知道宾语是谁，"鱼"说我是名词
- q("追") 和 k("的") 的点积很小 → 无关

**投影的作用就是重新定义"什么叫做相关"**——不是语义相关，而是"在当前任务中，我应该关注谁"。透镜的参数是训练数据教出来的，你不需要预设任何规则。

## 2.5 Key 和 Value 究竟有什么区别？

这是另一个容易困惑的问题：既然 K 和 V 来自同一个向量 $x$，为什么要分开投影？用同一个不就行了吗？

因为"怎么被找到"和"找到后贡献什么"是两件截然不同的事。

回到微信搜索的例子：
- **Key** = 从消息里提取的**索引关键词**（"周五"、"吃饭"、"海底捞"）——它是用来**被匹配**的
- **Value** = 那条消息的**完整内容**——它是匹配到之后**交付给你**的

在 Attention 中：
- **Key 决定匹配**：Q 和 K 做点积 → 得出权重，这个权重决定了"我有多关注这个位置"
- **Value 负责交付**：权重乘以 V 后求和 → 得出输出，这是实际被拿走的信息

分开投影意味着模型可以学会：$W_K$ 放大词性、位置、句法角色等信息（利于匹配），而 $W_V$ 保留完整语义信息（利于内容传递）。如果 K = V，这两件事被捆绑在一起，模型无法灵活分配。

**一句话总结 Q / K / V：**

| | 作用 | 类比 |
|---|---|---|
| **Q** | 我在找谁？需要什么信息？ | 搜索框输入 |
| **K** | 我是谁，你可以用什么关键词找到我？ | 索引关键词 |
| **V** | 找到我了，你要拿走什么内容？ | 实际消息内容 |

# 第三部分：Scaled Dot-Product Attention 的逐步推导

## 3.1 输入

输入是一个序列的表示矩阵 $X \in \mathbb{R}^{T \times d}$，$T$ 是序列长度，$d$ 是特征维度。

## 3.2 生成 Q、K、V

通过三个不同的线性变换，将输入投影为 Q、K、V：

$$Q = X W_Q, \quad K = X W_K, \quad V = X W_V$$

其中 $W_Q, W_K, W_V \in \mathbb{R}^{d \times d_k}$（通常 $d_k = d$）。

**数据流视角：** $X$ 是 $(T, d)$，三个 $W$ 各是 $(d, d_k)$，矩阵乘法的结果是三个 $(T, d_k)$ 的矩阵。序列中所有位置的向量被**同时、独立地**投影，没有任何位置间交互。

## 3.3 计算相关性分数

计算每个 Query 与每个 Key 的相似度（点积）：

$$S = Q K^T \in \mathbb{R}^{T \times T}$$

其中 $S_{ij}$ 是位置 $i$ 的 Query 和位置 $j$ 的 Key 的点积——它衡量"位置 i 想关注位置 j 的意愿有多强"。

为什么用点积？两个向量的点积衡量方向的一致性。当 q_i 和 k_j 方向一致时，它们在这个投影子空间中有相似的"朝向"，意味着它们可能是相关的。

## 3.4 缩放（Scaling）

$$S' = \frac{S}{\sqrt{d_k}}$$

**为什么除以 $\sqrt{d_k}$？** 假设 Q 和 K 的元素独立同分布、方差为 1，则它们的点积方差为 $d_k$。当 $d_k$ 很大时，点积值会很大，送入 softmax 后会落入饱和区（梯度接近零）。除以 $\sqrt{d_k}$ 做方差归一化，将方差压回 1，保证梯度流动。

## 3.5 softmax 归一化

$$A = \text{softmax}(S') \quad \text{(沿每一行做 softmax)}$$

softmax 确保每一行的权重和为 1，且权重集中在少数高相关的 Key 上。效果是："位置 i 的关注分配到了所有位置，但大部分注意力给了少数几个最相关的。"

## 3.6 加权求和

$$\text{Output} = A V \in \mathbb{R}^{T \times d}$$

每个输出位置得到的是所有 Value 的加权和，权重由 Attention 矩阵 $A$ 给出。

## 3.7 完整公式

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

## 3.8 数据流图

```
输入 X: (T, d)
    │
    ├── × W_Q → Q: (T, d_k)
    ├── × W_K → K: (T, d_k)
    └── × W_V → V: (T, d_k)
         │          │
         │     QK^T / √d_k
         │          │
         │     softmax  → 权重矩阵 A: (T, T)
         │          │
         └──  A × V ──┘
               │
          输出: (T, d_k)
```

# 第四部分：W_Q 的共享与不共享——单头、多头、多层

这是一个极其重要的结构性问题，理解它你就理解了 Attention 的参数组织方式。

## 4.1 单头注意力：同一头内，所有位置共享同一套参数

在**一个注意力头**里，只有一个 $W_Q$、一个 $W_K$、一个 $W_V$。序列中**所有位置（所有时间步）的词都用同一套矩阵做投影**。

这不是说所有位置的 q 都一样——每个位置有自己的 $x$，乘同一个 $W_Q$ 后得到**不同的 q**。但投影规则是所有位置共享的。这是参数共享的核心，也是 Attention 与位置无关性的来源。

## 4.2 单头注意力只能面向一个问题吗？

本质上是的。单头注意力里只有一套 $(W_Q, W_K, W_V)$，所以只能从**一种角度**去判断"谁跟谁相关"。就好比你戴着一种颜色的眼镜看世界，只能看到一种关联模式。

不过严格来说，$W_Q$ 是一个 $(d \times d_k)$ 的矩阵，它能把 $x$ 旋转到一个 $d_k$ 维的子空间。这个子空间本身可以编码多种查询方向——单头并非只能问"一个字面意义上的一个问题"。但实验证明，把一个大的投影空间**显式地切分成多个独立的小子空间**（即多头），效果更好。

## 4.3 多头注意力：每个头有自己独立的 W

Multi-Head Attention 里，Head 1 有 $(W_{Q1}, W_{K1}, W_{V1})$，Head 2 有 $(W_{Q2}, W_{K2}, W_{V2})$，…，每个头有全套参数。这就是多头的意义——**不同头学会关注不同类型的依赖**。

## 4.4 多层 Transformer：每一层有自己独立的 W

Transformer 堆了 N 层，第 1 层的所有头都有各自的一套参数，第 2 层也有一套，参数完全独立。每层学不同抽象层次的东西：底层学局部语法/声学模式，高层学语义/全局关系。

## 4.5 总览

```
Transformer (多层)
├── Layer 1
│   ├── Head 1 → (W_Q1, W_K1, W_V1)   ← 所有位置共享
│   ├── Head 2 → (W_Q2, W_K2, W_V2)   ← 所有位置共享
│   └── ...
├── Layer 2
│   ├── Head 1 → (W_Q1, W_K1, W_V1)   ← 不同于 Layer 1
│   └── ...
└── ...
```

三句话记住：
- **同一头内**：所有位置用同一套 $(W_Q, W_K, W_V)$
- **不同头**：各有各的一套，捕获不同模式
- **不同层**：各有各的一套，层次递进

如果模型有 16 层，每层 8 个头，那总共有 $16 \times 8 = 128$ 组不同的 $(W_Q, W_K, W_V)$，每组各司其职。

# 第五部分：Self-Attention vs Cross-Attention

在理解了基本 Attention 之后，需要区分两种使用模式：

## Self-Attention（自注意力）

**Q、K、V 来自同一个序列。** 即输入序列的每个位置去"关注"同一个序列的所有其他位置。

这允许序列内部的信息交互——每个词可以看到同一句话中的所有词。这是 Transformer 的核心机制。

$$\text{SelfAttn}(X) = \text{softmax}\left(\frac{(XW_Q)(XW_K)^T}{\sqrt{d_k}}\right)(XW_V)$$

## Cross-Attention（交叉注意力）

**Q 来自一个序列，K 和 V 来自另一个序列。** 典型场景是 Encoder-Decoder 结构中的解码器：解码器的 Query 去"询问"编码器输出的 Key 和 Value。

这实现了两个不同序列之间的信息传递。比如在翻译任务中，每生成一个目标语言词，就去源语言句子中找最相关的信息。

# 第六部分：Multi-Head Attention 的完整形态

## 为什么需要多头

单头 Attention 的问题在于：只有一个投影子空间，表达能力受限。在实际任务中，一个词需要从多个维度关注不同的信息。

比如翻译"猫吃了鱼"时：
- 翻译"吃"需要关注"猫"（主语-动词关系）
- 也需要关注"鱼"（动词-宾语关系）
- 还可能需要关注时态信息

多头设计的思路是：**并行运行多个独立的 Attention，每个头关注不同的模式，最后拼接起来。**

## 具体操作

```
输入 X: (T, d)
    │
    ├── 给每个头 i 生成 Q_i, K_i, V_i  (各自独立的 W 投影)
    ├── 每个头独立计算 Attention
    │
    Head_1 = Attention(Q_1, K_1, V_1)  → (T, d_head)
    Head_2 = Attention(Q_2, K_2, V_2)  → (T, d_head)
    ...
    Head_H = Attention(Q_H, K_H, V_H)  → (T, d_head)
    │
    └── Concat[Head_1, ..., Head_H] → (T, H × d_head)
         │
         Linear → (T, d)
```

通常 $d_{head} = d / H$，比如 $d = 512, H = 8, d_{head} = 64$。这样拼接后维度不变，总参数量也与单头 Attention 相同（因为每个头的 Q、K、V 投影维度变小了）。

## Multi-Head Attention 的完整形式

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_H) W_O$$

$$\text{head}_i = \text{Attention}(QW_{Qi}, KW_{Ki}, VW_{Vi})$$

# 第七部分：从信号处理的角度理解 Attention

如果你有信号处理的背景，这个操作有一个非常优雅的类比：

$$\text{Output} = \text{softmax}(QK^T / \sqrt{d_k}) \cdot V$$

其中 $\text{softmax}(QK^T / \sqrt{d_k})$ 是一个 $(T \times T)$ 的矩阵。它作用在 Value 序列上的效果是：**它是一个数据依赖的、非线性的、全局的混合矩阵**。每个输出位置 $j$ 是输入位置 $i$ 的加权混合：

$$\text{Output}_j = \sum_i A_{ji} \cdot V_i$$

这和线性系统中的混合矩阵概念完全一致，只不过这里的混合系数 $A_{ji}$ 不是固定的，而是根据数据内容动态计算的。**你可以把 Self-Attention 理解为：一个自适应的、数据依赖的全通滤波器组。**

# 第八部分：Transformer 的整体架构

在理解了 Attention 之后，Transformer 的完整架构就水到渠成了。

## 核心认知

> Transformer 不做时序处理，它只做信息重排和特征变换。

这是理解 Transformer 最关键的一点：它没有 RNN 那样的逐步传播，而是将整个序列**同时处理**。输入序列的每个位置，在 Attention 层中"一次性"看到所有其他位置。这就是为什么它能并行计算。

## 编码器（Encoder）

```
输入序列 (经过 Embedding 和位置编码)
    │
    ▼
┌──────────────────────┐
│ N × EncoderLayer     │
│                      │
│  Multi-Head          │
│  Self-Attention   ──残差──→ Add & LayerNorm
│                      │
│  Feed-Forward      ──残差──→ Add & LayerNorm
│                      │
└──────────────────────┘
    │
    ▼
编码输出 (上下文表示)
```

一个 EncoderLayer 做的事：
1. 输入做 LayerNorm → Multi-Head Self-Attention → 加残差 → LayerNorm
2. 上一步的输出做 LayerNorm → FFN → 加残差 → LayerNorm

## 解码器（Decoder）

解码器比编码器多一个 Cross-Attention 层：

```
目标序列 (右移一位，刚开始是<SOS>)
    │
    ▼
┌──────────────────────┐
│ N × DecoderLayer     │
│                      │
│  Masked Multi-Head   │
│  Self-Attention   ──残差──→ Add & LayerNorm
│                      │
│  Multi-Head          │
│  Cross-Attention  ──残差──→ Add & LayerNorm  ← Q 来自 Decoder, K/V 来自 Encoder
│                      │
│  Feed-Forward      ──残差──→ Add & LayerNorm
│                      │
└──────────────────────┘
    │
    ▼
Linear → Softmax → 输出概率分布
```

## Masked Self-Attention（因果掩码）

在解码器中，生成第 t 个词时，不能"偷看"第 t+1 个及之后的词（因为那些还没生成）。所以需要**掩码**：把 Attention 矩阵的上三角区域设为 $-\infty$（这样 softmax 后权重为 0）。

```
原始权重矩阵 A:         加上掩码后:
[ a11  a12  a13  a14 ]   [ a11  -∞   -∞   -∞  ]
[ a21  a22  a23  a24 ]   [ a21  a22  -∞   -∞  ]
[ a31  a32  a33  a34 ]   [ a31  a32  a33  -∞  ]
[ a41  a42  a43  a44 ]   [ a41  a42  a43  a44 ]

softmax 后权重:
[ 1.0  0    0    0   ]
[ w21  1-w21 0    0   ]
[ w31  w32  1-.. 0   ]
[ w41  w42  w43  w44 ]
```

## Feed-Forward Network (FFN)

每个 Attention 层之后都跟一个 FFN：

$$\text{FFN}(x) = \text{ReLU}(x W_1 + b_1) W_2 + b_2$$

其中 $W_1 \in \mathbb{R}^{d \times 4d}$，$W_2 \in \mathbb{R}^{4d \times d}$。

**为什么需要 FFN？** Attention 做的是序列中的信息混合（跨位置的线性组合），但缺乏逐位置的非线性变换。FFN 是对每个位置独立作用，提供非线性变换和维度扩展-压缩的空间（4 倍扩展）。

从数学角度理解：Attention 是**跨位置的混合**，FFN 是**逐位置的非线性变换**。两者互补——Attention 负责"交流"，FFN 负责"思考"。

# 第九部分：位置编码（Positional Encoding）

## 问题的提出

观察 Attention 公式：$\text{softmax}(QK^T / \sqrt{d_k}) V$

对于任意排列 $\pi$，如果输入序列完全打乱，输出也会被相应地打乱——但 Attention 权重本身无法区分"谁先谁后"。因为 Attention 是不包含位置信息的置换等变操作。

这意味着"猫追狗"和"狗追猫"在 Attention 中本质上没有区别——所有词都在互相看到对方，没有"顺序"的概念。

## 解决方案：加入位置信息

### 正弦位置编码（Original Transformer）

为每个位置 $pos$ 和每个维度 $i$ 计算：

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d}}\right)$$

$$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

然后将位置编码直接加到输入 Embedding 上：$X_{input} = X_{embed} + PE$

**为什么选择正弦 / 余弦？** 因为存在恒等式：

$$\sin(a+b) = \sin(a)\cos(b) + \cos(a)\sin(b)$$
$$\cos(a+b) = \cos(a)\cos(b) - \sin(a)\sin(b)$$

对于任意偏移量 $k$，$PE_{pos+k}$ 可以表示为 $PE_{pos}$ 的线性变换。这意味着模型容易学习相对位置关系——"前一个"和"当前"的相对关系在所有绝对位置上是同一种模式。

### 可学习位置编码

直接为每个位置学习一个可训练的嵌入向量。好处是灵活，坏处是无法外推到训练时没见过的序列长度。

### 相对位置编码（用于 Conformer / Transformer-XL）

不定义绝对位置编码，而是直接建模两个位置之间的**相对距离**。公式变为：

$$A_{ij} = Q_i K_j^T + Q_i R_{i-j}^T$$

其中 $R$ 只依赖于相对距离 $i-j$。这种方法更符合音频/语言的直觉——"相邻"是一个相对概念。

# 第十部分：Layer Normalization (LayerNorm)

## 它做了什么

LayerNorm 对一个样本在特征维度上做归一化：

$$\hat{x}_k = \frac{x_k - \mu}{\sqrt{\sigma^2 + \epsilon}}, \quad y_k = \gamma \hat{x}_k + \beta$$

其中 $\mu = \frac{1}{d}\sum x_k$（特征维度的均值），$\sigma^2 = \frac{1}{d}\sum (x_k - \mu)^2$，$\gamma$ 和 $\beta$ 是可学习的缩放和平移参数。

## 为什么需要它

深层网络中，各层的输出分布会不断漂移（内部协变量偏移）。这导致梯度不稳定、训练变慢、需要小心初始化。LayerNorm 将每一层的输出"拉回"到均值为 0、方差为 1 的分布，然后通过可学习的 $\gamma$ 和 $\beta$ 重新调整，稳定深层网络的训练。

# 第十一部分：残差连接

Transformer 中每个子层（Attention、FFN）都有残差连接：

$$\text{Output} = \text{Input} + \text{Sublayer}(\text{LayerNorm}(\text{Input}))$$

**Post-Norm vs Pre-Norm：** 原始 Transformer 将 LayerNorm 放在残差之后（Post-Norm）。后来的研究（包括 Conformer）发现放在残差之前（Pre-Norm）训练更稳定，尤其是在深层网络中。因为 Pre-Norm 让梯度可以通过残差连接"直通"到早期层。

残差连接本质上是为梯度提供了一条"高速公路"，每一层的梯度等于：
$$\text{grad} = \text{grad}_{skip} + \text{grad}_{sublayer}$$

即使子层的梯度很小时，skip 连接的梯度也能保证有效的信息传播。

# 第十二部分：完整的数据流

以一个简化的 Encoder 为例，追踪一个 batch 的数据：

```
输入: 一句话 → Tokenizer → Token IDs: (B, T)

Step 1: Embedding
  Token IDs → Embedding Table → (B, T, D_emb)
  
Step 2: 位置编码
  (B, T, D_emb) + Positional Encoding → (B, T, D_emb)

Step 3: EncoderLayer × N
  
  对于每一层:
  
  ┌─ 输入 x: (B, T, D) ────────────────────────────┐
  │                                                 │
  │  x_norm = LayerNorm(x)                          │
  │  attn_out = MultiHeadAttn(x_norm, x_norm, x_norm) │
  │  attn_out = Dropout(attn_out)                   │
  │  x = x + attn_out          ← 残差连接           │
  │                                                 │
  │  x_norm = LayerNorm(x)                          │
  │  ffn_out = FFN(x_norm)     ← Linear→ReLU→Linear │
  │  ffn_out = Dropout(ffn_out)                     │
  │  x = x + ffn_out           ← 残差连接           │
  │                                                 │
  └─ 输出 x: (B, T, D) ─────────────────────────────┘

Step 4: 输出
  最后一层的输出可以用于各种下游任务：
  - 分类：取第一个 token 的表示 → Linear → Softmax
  - 序列标注：每个位置 → Linear → Softmax
  - 生成：接 Decoder
```

# 第十三部分：Transformer 的计算复杂度

## Self-Attention 的复杂度分析

Attention 的核心计算是 $QK^T \in \mathbb{R}^{T \times T}$，复杂度为 $O(T^2 \cdot d)$。

- **与序列长度呈平方关系**：这是 Transformer 最大的弱点。对于长音频（比如 44.1kHz 采样，10 秒音频 = 441000 个采样点），直接使用 Self-Attention 极其昂贵。
- 这就是为什么在音频处理中，前面会用卷积下采样大幅降低序列长度，以及为什么 Conformer 引入了卷积模块来弥补局部采样的不足。

## FFN 的复杂度

FFN 只做逐位置变换：$O(T \cdot d \cdot d_{ff})$，与序列长度呈**线性**关系。

## 对比

| 模块 | 计算复杂度 | 内存复杂度 |
|------|-----------|-----------|
| Self-Attention | $O(T^2 d)$ | $O(T^2)$ |
| FFN | $O(T d d_{ff})$ | $O(T d)$ |
| Convolution (kernel K) | $O(T d K)$ | $O(T d)$ |

这解释了为什么长序列处理中，Self-Attention 是瓶颈。

# 总结：你应该记住的核心要点

1. **Q、K、V 的本质**：同一个输入 $x$ 经过三个不同的可训练矩阵投影，得到三个不同的"观察角度"。Q 管查询意图，K 管被查标签，V 管实质内容
2. **参数共享规则**：同一头内所有位置共享，不同头各自独立，不同层各自独立
3. **Attention 的本质**：数据依赖的全局加权求和，让每个位置可以"关注"所有其他位置
4. **Self-Attention vs Cross-Attention**：前者用于序列内部交互，后者用于序列间交互
5. **Multi-Head**：多个并行的注意力头，捕获不同类型的依赖关系
6. **Transformer 的核心设计**：Attention 负责跨位置信息混合，FFN 负责逐位置非线性变换，残差 + LayerNorm 保证训练稳定性
7. **位置编码**：必不可少的组件，让无序的 Attention 感知到序列的顺序
8. **复杂度瓶颈**：$O(T^2)$ 是 Attention 的致命弱点，需要下采样或其他技巧

理解了这些，再去读 Conformer 就会非常顺畅：Conformer 只是在 Transformer Block 中多插入了一个 Convolution Module，让局部建模能力与全局 Attention 能力互补。本质上的设计语言是完全一致的。
