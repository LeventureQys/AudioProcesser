# 00 阅读指南：两卷书、一个问题——这套讲解文档怎么用

> 本指南是《统计信号处理基础——估计与检测理论》（Steven M. Kay 著，中译本）讲解系列的全局导览。
> 系列文档位于 `Document/统计信号处理/Documents/`，每章一篇，命名 `Vol1_ChNN_章名.md`（第一卷）与 `Vol2_ChNN_章名.md`（第二卷）。

## 写在前头

这套文档的目标读者：**有 DSP 基础、想补统计信号处理理论的工程师**。原著两卷合计 28 章 880 余页，公式密集、推导冗长；本系列把每一章改写为"工程手记"式讲解——**先讲为什么、再讲怎么做，保留结论性公式，省去推导长链，重点放在性质与限制上**。

一句话概括两卷的分工：**第一卷回答"参数是多少"（估计），第二卷回答"信号在不在"（检测）；估计是检测的工具箱，所以顺序不可颠倒。**

**实测声明**：本系列全部章节的事实性内容（公式编号、例子编号、定理、表格数值）均经原书扫描件 OCR 核对（素材存 `Temp/chapters_ocr/`），页码映射规则见下文；自建演示图为脚本生成、种子固定、可复现。这不是对原书的转述堆砌，而是"原书为据、问题为纲"的重写。

## 二、学习路线

### 路线 A：估计理论卷（主线，顺序读）

```
Ch01 引言（定观念：估计量是随机变量）
  → Ch02 MVU（最好长什么样） → Ch03 CRLB（精度天花板在哪）
  → Ch04 线性模型（最常用场景的现成答案） → Ch05 充分统计量（信息无损压缩）
  → Ch06 BLUE（不用高斯假设的最优线性解）
  → Ch07 MLE（实用主义主力：渐近最优） → Ch08 最小二乘（不要概率假设的万能法） → Ch09 矩方法（最朴素）
  → Ch10 贝叶斯原理（把先验知识请进来） → Ch11 MMSE/MAP → Ch12 线性 MMSE 与维纳滤波
  → Ch13 卡尔曼滤波（动态系统的贝叶斯集大成） → Ch14 估计量总结（选型） → Ch15 复数据扩展
```

节奏建议：Ch02~Ch04 是理论核心，值得细读并做原书习题；Ch07 是全书工程价值最高的一章，它的例子（匹配滤波、周期图、波束形成、LPC）会在第二卷反复回收；Ch08/Ch09 可快读（对照 Ch07 理解"放弃概率假设/放弃最优性"的代价）；Ch10~Ch13 是第二条腿（贝叶斯），与 Ch01 的 §2.3 伏笔对接。

### 路线 B：检测理论卷（第二卷）

```
Vol2 Ch01 引言（检测问题的四要素） → Vol2 Ch02 重要 PDF 总结（当手册查）
  → Vol2 Ch03 判决理论 I（NP 准则、ROC、贝叶斯风险——检测的地基）
  → Vol2 Ch04 确定信号（匹配滤波器） → Vol2 Ch05 随机信号（估计器-相关器）
  → Vol2 Ch06 判决理论 II（参数未知怎么办：GLRT、Rao）
  → Vol2 Ch07~09（未知参数信号/未知噪声的实战） → Vol2 Ch10 非高斯噪声
  → Vol2 Ch11 检测器总结（选型） → Vol2 Ch12 模型变化检测 / Ch13 复矢量与阵列
```

第二卷每一章都在"假设越来越少、检测器越来越妥协"，读的时候建议始终问一个问题：**这一章比上一章少知道了什么，检测器为此付出了什么代价？**

## 三、记号与页码约定（全系列统一）

1. **页码**：本扫描 PDF 自正文起，**书内页码 = PDF 页码 − 15**（两卷同规则，实测校订）。各章引用以"原书式 (x.y) / 例 x.y / 图 x.y / 表 x.y"为准，并给出 PDF 页码便于查证。
2. **公式/例子/图/表编号沿用原书**，未编号的推导补充由各章注明。
3. **记号**：$\hat{\theta}$ 表示估计量（帽子）；$p(\mathbf{x};\theta)$ 是经典记号（$\theta$ 为确定参数），$p(\mathbf{x}\mid\theta)$ 是贝叶斯记号（$\theta$ 为随机变量）；$E[\cdot]$、$\mathrm{var}(\cdot)$ 为标准期望/方差；$\mathcal{N}(\mu,\sigma^2)$ 为高斯分布。其余符号各章就地定义。
4. **引用的章**："原书第 N 章"指 Kay 原书章节；"本系列第 N 篇"指本目录下的 `VolX_ChNN` 文档。
