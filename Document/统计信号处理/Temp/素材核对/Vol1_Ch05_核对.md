## 2. 据英文原版校订处

1. **例 5.8 的 $\beta/\theta$ 口径（式 5.9、5.10）**：OCR 页 110 L9~12 为"var(0) / 82 / (5.9) / 12N"，页 112 L12~13 为"最小方差为 / 32 / (5.10)"，分子"82""32"无法分辨是 $\beta^2$ 还是 $\theta^2$。据 Kay 英文原版（Vol I, Example 5.8）：数据 $w[n]\sim U(0,\beta)$、$\theta=\beta/2$，**式（5.9）为 $\mathrm{var}(\bar{x})=\beta^2/(12N)$、式（5.10）为 $\mathrm{var}(\hat{\theta})=\beta^2/[4N(N+2)]$**。理由：① $\mathrm{var}(\bar{x})=\beta^2/(12N)$ 是 $U(0,\beta)$ 方差 $\beta^2/12$ 除以 $N$ 的直接结果（若写成 $\theta$ 口径应为 $\theta^2/(3N)$，与 OCR"12N"不符，故分子应为 $\beta^2$）；② $\hat{\theta}=\frac{N+1}{2N}\max x[n]$，$\mathrm{var}(T)=N\beta^2/[(N+1)^2(N+2)]$，乘 $((N+1)/(2N))^2$ 得 $\beta^2/[4N(N+2)]$（等价 $\theta^2/[N(N+2)]$），与"MVU 随 $1/N^2$、样本均值随 $1/N$"的定性结论（OCR 页 112 L16~17）自洽。
2. **例 5.11 的 CRLB "21"**：OCR 页 116 L15~16 为"而 CRLB是(参见例 3.6) / 21"，据例 3.6（第 3 篇核对一致）应为 $2\sigma^4/N$。校订依据：$\mathrm{var}(\hat{\sigma}^2)=2\sigma^4/(N-1)$（由 $(N-1)\hat{\sigma}^2/\sigma^2\sim\chi^2_{N-1}$、$\chi^2_\nu$ 方差 $2\nu$），与 CRLB $2\sigma^4/N$ 相差 $1/(N-1)$ vs $1/N$，正是"MVU 但不有效"的出处。
3. **各处指数/求和展开**：OCR 对数学式整体识别差（页 102~104、114~116 的指数、求和、矩阵大量残断），均按标准高斯 PDF 展开与 Kay 英文原版补齐，未发现与结论冲突处。
4. 其余公式编号（5.1）~（5.12）、定理 5.1~5.4、例 5.1~5.11、图 5.1~5.5、习题 5.1~5.19 均以 OCR 为准，未发现需校订处。
