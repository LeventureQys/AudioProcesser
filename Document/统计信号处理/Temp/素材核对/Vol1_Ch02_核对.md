## 2. 据英文原版校订处

1. **例 2.3 的 PDF 写法**：OCR 页 33 L23~27 为"z[0]～N(3,1)"与"x[1]～N(0,1), θ≥0 / N(0,2), θ<0"。据 Kay 英文原版（Vol I, Example 2.3），应为 $x[0]\sim\mathcal{N}(\theta,1)$、$x[1]\sim\mathcal{N}(\theta,1)\ (\theta\ge0)$ / $\mathcal{N}(\theta,2)\ (\theta<0)$（均值是 $\theta$，不是 0；"3" 是 $\theta$ 的误认）。理由：两个估计量都需 $E[x[0]]=E[x[1]]=\theta$ 才"无偏"，若均值是 0 则无偏性不成立，与后文"很容易证明是无偏的"矛盾。
2. **例 2.3 的方差数值**：OCR 页 34 出现"27/36、24/36、20/36、82、18/36"，其中"82"为噪点，忽略。四个有效值 18/36、20/36、24/36、27/36 与英文原版一致，已用于正文表格与 Fig005(b)。
3. **习题 2.11 的分布与无偏条件**：OCR 页 36 L39 作"从分布 u[0,119]"，页 37 作"g(u) du = 1"。据 Kay 英文原版 Problem 2.11，分布应为 $\mathcal{U}(0,1/\theta)$（区间 $[0,1/\theta]$ 上的均匀分布），无偏条件为 $\int_0^{1/\theta} g(u)\,du = 1$（"119" 是 "$1/\theta$" 的误认；积分上限是 $1/\theta$ 而非 $\theta$）。理由：均匀密度为 $\theta$，$E[g(x[0])]=\theta\int_0^{1/\theta}g(u)du$，令其等于 $\theta$ 即得 $\int_0^{1/\theta}g(u)du=1$；该式对所有 $\theta>0$ 无解（正文 §3.3 论证）。
4. 其余公式编号（2.1）~（2.7）与例子编号、图编号、习题编号均以 OCR 为准，未发现需校订处。
