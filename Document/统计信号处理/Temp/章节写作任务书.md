> 本任务书为所有章节的公共规范；每章的具体指派（章节名、OCR 目录、图片编号、输出路径）由主代理在派发消息中给出。

## 0. 必读材料（按顺序读）

1. `Document/工程写作规范.md` —— 写作规范，骨架与叙事原则必须遵守；
2. 样章范本（风格与结构的直接样板，务必通读模仿）：
   - `Document/统计信号处理/Documents/Vol1_Ch01_引言.md`（短篇：定基调）
   - `Document/统计信号处理/Documents/Vol1_Ch07_最大似然估计.md`（全风格样板：问题→直觉→理论→性质与限制→例子→图）
3. `Document/统计信号处理/Temp/全书目录整理.md` —— 章节目录、全书主线；
4. 本章 OCR 素材（主代理指定目录，如 `Temp/chapters_ocr/ch03/ocr_page_*.txt`，文件名中数字 = PDF 页码）。

## 1. 事实红线（最高优先级）

- 文中**所有**公式编号、定理编号、例子编号、图表编号、数值必须与 OCR 文本核对一致；OCR 识别不清处，用你对 Kay 原书（Fundamentals of Statistical Signal Processing, Vol I/II, Prentice Hall）的可靠知识补齐，并注明"据 Kay 原书英文版校订"；仍拿不准的，宁可略去并明说"原书此处在扫描件中不可辨，略"。
- **禁止编造数值、形状、指标**。自建仿真图除外（需写明种子与参数）。
- 页码映射：**书内页码 = PDF 页码 − 15**（第一卷自书内 12 页起、第二卷全书实测成立）。正文引用以"原书式 (x.y) / 例 x.y / 图 x.y / 表 x.y + 所在 PDF 页"的方式给出。

## 2. 文章骨架（强制，每章必须齐全）

1. 标题：`# VolX_ChNN_章名：一句问题式副标题`（副标题要像样章那样有钩子）；
2. 开头引用块：对应原书卷/章/页码（书内+PDF 页码）、前置阅读；
3. **写在前头**：定位（本章在全书链条中的位置）、一句话设计目标、**实测声明**（核对自哪些 OCR 文件）；
4. **正文 1..N 章**：沿"问题→理论→性质与限制→例子"推进；每节开头提出一个明确的"为什么"；节末尽量有加粗一句话总结；
5. **关键设计决策回顾**（表格：决策/为什么/换一个选择会怎样）；
6. **实现备忘**（对照原书时的坑、页码/记号/口径陷阱）；
7. **局限**（坦率列短板，标注由哪一章/哪卷解决；就是后续章节的存在理由）；
8. **建议自测的问题** 3~5 个（可标注对应原书习题号）；
9. 结尾：**一句话收尾**（加粗）+ 实测核对声明（斜体）。

## 3. 叙事与表达

- 问题驱动、为什么先于怎么做、层层递进（起点→局限→升级），升级必须是必然的；
- 直觉先行+类比辅助（类比后必须跟上公式/形状/参数量等严谨内容，类比不得替代论证）；
- 术语后给"翻译成人话"的一句话；允许克制人称化语气，结论必须严谨；
- 公式用 LaTeX，**所有符号就地定义**；公式后立即回答"说明什么性质、什么条件下成立、何时失效"；不展开冗长推导，推导结论注明原书小节；
- 表格前后要有文字引导；前置概念用引用块就地插播，保证文章自包含（读者不读其他章节也能懂）；
- 伏笔/回调只允许指向真实存在的章节（本系列其它章用"原书第 N 章/本系列第 N 篇"字样），禁止虚指；
- 读者画像：有 DSP 基础的工程师，重视"性质与限制"胜过推导。

## 4. 图片规范（严格）

- 配图原则：**服务结论、宁缺毋滥**；每章 0~2 张（主代理已预分配编号，可少用不可多用、不可自造编号）；
- 脚本放 `Document/统计信号处理/Temp/scripts/make_figNNN.py`（NNN=分配编号），图片输出 `Document/统计信号处理/Documents/figures/FigNNN_中文名.png`；
- 脚本必须：`from plotutil import setup_cn, check_figure`（plotutil 在同目录，已存在，勿修改）；先 `setup_cn()`，绘制完成后 `check_figure(fig)`，**通过后才 savefig**（check_figure 会拒绝保存有穿框/重叠问题的图）；
- 布局纪律：图元先规划坐标再落笔；节点框之间、框与文本之间留足间距；连线避开节点框与文本；图例放空白区；坐标轴留 5~10% 余量；中文用 plotutil 配置的字体；
- 生成后用 `py -3.14 make_figNNN.py` 运行（在 `Temp/scripts` 目录下），**必须看到 "saved ..." 输出才算成功**；
- 正文必须引用图编号 + 图注（斜体）：图是什么、关键看点、支持哪条结论；
- 图内容更新保留原编号；若决定某章不配图，在交付报告中说明即可（编号保留"未使用"状态，不得挪作他用）。
