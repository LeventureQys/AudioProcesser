SUBROUTINE STATS(X,N,XMEAN,XVAR)
This program computes the sample mean and variance
of a data set.
Input parameters:
- Array of dimesion Nxl containiag data
- Number of data set
Output parameters:
XMEAN - Sample mean
XVAR - Sample variance
DIMENSION X(1)
XMEAN=0.
XSQ-0.
DO 10 I=1,N
XMEAN=XMEAN+X(I)/N
10
XSQ=XSQ+X(I)*X(I)/N
XVAR=XSQ-XMEAN*XMEAN
RETURN
END
